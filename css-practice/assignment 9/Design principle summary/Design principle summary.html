```html Responsive Design Principles
Responsive Design Principles

Three important principles for creating responsive websites

Fluid Layouts

Fluid layouts use flexible units such as percentages, allowing content to adjust according to screen size.

width: 100%;
max-width: 1200px;

Flexible Media

Flexible media allows images and videos to resize automatically so they fit different screen sizes.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Breakpoints use media queries to change the layout when the screen reaches a specific width.

@media (max-width: 600px) {
  .container {
    width: 100%;
  }
}
```
