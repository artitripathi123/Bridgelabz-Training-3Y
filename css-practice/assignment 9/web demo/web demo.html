Responsive Design

Responsive web design is an approach that allows websites to adjust their layout and content according to different screen sizes and devices.

CSS Grid can be used for page layouts, while Flexbox is useful for navigation and arranging elements in a row or column.

Media queries allow developers to apply different CSS rules for desktops, tablets, and mobile devices.

Example: @media (max-width: 700px) { }

CSS Cheat Sheet

Flexbox

Used to arrange elements in rows or columns.

display: flex;

Grid

Creates rows and columns for page layouts.

display: grid;

Media Query

Changes styles according to screen size.

@media (max-width: 700px)

Transition

Creates smooth changes between CSS states.

transition: 0.3s;
