```html Responsive CSS Cheat Sheet
Responsive CSS Cheat Sheet

Quick reference for important responsive CSS concepts

Filters

CSS filters can change the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply different styles based on screen size.

@media (max-width: 700px) { }

Responsive Design

Responsive design makes a website adjust properly to different screen sizes and devices.

width: 100%;

Typography

Typography controls the appearance, size, and spacing of text on a webpage.

font-size: 1.2rem;

CSS Grid

CSS Grid creates rows and columns for arranging webpage content.

display: grid;

Flexbox

Flexbox helps arrange elements in a flexible row or column.

display: flex;
```
